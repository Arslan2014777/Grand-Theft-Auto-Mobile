# Grand-Theft-Auto-Mobile
🎮 GTA 6 Mobile

Unofficial fan-made mobile game project inspired by Grand Theft Auto VI.

Welcome to GTA 6 Mobile — an ambitious mobile gaming project inspired by the world of GTA VI.

🌴 About the Project

GTA 6 Mobile is a fan-made project aiming to bring the atmosphere of Grand Theft Auto VI to mobile devices.

The project is developed independently and is not affiliated with Rockstar Games.

🎯 Features

* 📱 Mobile-friendly gameplay
* 🌴 Open-world inspired environment
* 👥 Male and female playable characters
* 🚗 Vehicles and exploration
* 🎮 Simple and accessible controls

Features are subject to change during development.
